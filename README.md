# 🛗 Techno 4ème — Cahier des charges (site interactif)

Site web pédagogique interactif pour expliquer le **Chapitre 1 — Exprimer un besoin par un cahier des charges** aux élèves de 4ème en Technologie.

> Exemple fil rouge : **rendre un ascenseur domestique accessible à un fauteuil roulant**.

## 📁 Contenu du dépôt

| Fichier | Rôle |
|---|---|
| `techno4-cahier-charges.html` | **Fichier principal — autonome** (CSS + JS intégrés). Double-cliquer dessus suffit pour l'ouvrir dans un navigateur. |
| `index.html` + `styles.css` + `script.js` | Version « séparée » équivalente, si tu préfères cette structure. |
| `README.md` | Ce fichier. |

## 🚀 Mettre en ligne sur GitHub Pages (30 secondes)

1. Crée un nouveau dépôt sur GitHub (nom au choix, par ex. `techno4-cahier-charges`).
2. Active **Settings → Pages → Deploy from a branch → `main` / `root` → Save**.
3. Upload **uniquement le fichier `techno4-cahier-charges.html`** (ou renomme-le en `index.html` si tu veux qu'il s'ouvre directement à la racine du site).
4. Patiente ~1 min → ton site est en ligne à l'adresse `https://<ton-user>.github.io/<nom-du-repo>/`.

> 💡 Astuce : si tu veux que le site s'ouvre directement à la racine du GitHub Pages (sans `/nom-du-repo/` dans l'URL), crée plutôt un dépôt nommé `<ton-user>.github.io` et mets-y le fichier `index.html`.

## ✏️ Modifier le contenu

Ouvre `techno4-cahier-charges.html` dans un éditeur (VS Code, Notepad++, Sublime Text…). Tout est dedans :
- Le contenu est en HTML classique,
- Le design est en CSS dans le bloc `<style>...</style>`,
- L'interactivité (QCM, corrections) est en JS dans le bloc `<script>...</script>`.

## 📚 Sections du site

1. 🏠 Accueil — présentation + parcours
2. 🔍 Observer — situation problème, fonctions / contraintes de l'ascenseur
3. 📐 Étude — fauteuil roulant, accessibilité cabine
4. ✏️ Résoudre — Méthode 1 (modifier) et Méthode 2 (rédiger)
5. 💡 Apprendre — « Je retiens » + « Je sais faire »
6. 🎯 S'entraîner — 5 exercices interactifs avec correction pas à pas
7. 🎓 Vers le brevet — drone livreur de pizzas
